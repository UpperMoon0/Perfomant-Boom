# Perfomant Boom 1.1.2

- Move bootstrap and loader entrypoint classes out of generic `com.nstut`, `com.nstut.forge`, `com.nstut.fabric`, and `com.nstut.neoforge` packages into `com.nstut.perfomantboom.*`.
- Prevent Java module-layer split-package failures when Perfomant Boom is installed alongside other NsTut mods such as Economy.
- Keep the reusable `com.nstut.explosion.*` and terrain API packages unchanged so existing Boom integrations do not need source changes.
