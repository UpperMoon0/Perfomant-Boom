# 1.1.2

- Move common and loader entry points into `com.nstut.perfomantboom` so Forge can load Boom alongside Meconomy without duplicate `com.nstut` and `com.nstut.forge` packages.
- Preserve the `com.nstut.explosion` terrain API used by Celestial Nail.
- Add `scripts/CheckForgeModules.java` to check real packaged jars with Java's module resolver. Run `java scripts/CheckForgeModules.java <boom.jar> <economy.jar> <celestial-nail.jar>` after building.

These notes describe source changes, not a published release.
