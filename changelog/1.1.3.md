# 1.1.3

- Reduce 1.20.1 ray-loop allocation by using a mutable position only for set lookups and creating immutable selected positions only on first insertion. Preserve vanilla's affected-set insertion order, full shuffle and level RNG state.
- Reuse an immutable coordinate for consecutive modern ray samples in the same block. Resistance and selection callbacks still run on every sample, and retained callback positions stay stable across yields.
- Avoid repeated chunk-map lookups while ray samples remain in the current chunk. Discard both the current-chunk reference and slice cache at every yield so unloaded/replaced chunks are reacquired.
- Extend forced-yield shuffle/RNG, callback retention and chunk replacement regression coverage.
- Give live-test coordination files unique trial names to avoid replacing a file while the Windows client reads it. Add optional server JFR profiling for diagnosis; profiled runs cannot generate publication charts.
- Keep benchmark data and charts versioned so earlier measurements remain available.

- Real 1.20.1 Fabric/Forge server and graphical-client suites passed. In the power-10 no-drops fixture, median server-thread allocations were 11–14% below the archived v1.1.2 runs; timings come from separate sessions and do not establish a controlled version-to-version speedup.

These notes describe source changes, not a published release. Live performance results and their limits are documented in `docs/BENCHMARKS.md`.
